Kiến trúc backend hiện tại:
  - Framework:        FastAPI (prefix /api/v1)
  - ML Runtime:       ONNX Runtime only (KHÔNG còn TF/Keras)
  - Classifier:       OnnxClassifierAdapter (lazy-load singleton)
  - Preprocessing:    mobilenet_v2 → (x / 127.5) - 1.0
  - Temperature:      T = 0.5204 (qua _apply_temperature_scaling)
  - RAM Limit:        512MB (Render Free Tier)
  - Inference:        asyncio.Semaphore(1) — 1 request đồng thời
  - Model path:       models/classifiers/mobilenetv2_final.onnx
  - Input format:     NHWC (batch, 224, 224, 3)
  - Class names:      7 lớp [BNE, EO, IG, MYO, NEU, PMY, SNE]

Kiến trúc frontend hiện tại:
  - Framework:        Next.js 16 + React 19
  - Styling:          TailwindCSS v4
  - State:            Zustand + @tanstack/react-query
  - API Client:       apiPostForm() → /api/v1/*
  - XAI sẽ tích hợp: PreviewModal trong cell-review-gallery.tsx

CÁC ĐIỀU CHỈNH SO VỚI KẾ HOẠCH GỐC:

  [1] THUẬT TOÁN: Grad-CAM → EigenCAM
      Lý do: ONNX không có autograd. EigenCAM dùng PCA trên feature maps,
      không cần gradient, hoạt động 100% trên ONNX Runtime.

  [2] PREPROCESSING: ImageNet normalize → mobilenet_v2
      Gốc:  (x - [0.485,0.456,0.406]) / [0.229,0.224,0.225]  ← SAI
      Sửa:  (x / 127.5) - 1.0                                 ← ĐÚNG
      Phải khớp với apply_model_preprocessing() trong classifier_service.py

  [3] INPUT FORMAT: NCHW → NHWC
      Gốc:  np.transpose(img, (2,0,1))  → (1,3,224,224)  ← SAI cho TF model
      Sửa:  np.expand_dims(img, 0)      → (1,224,224,3)  ← ĐÚNG cho ONNX TF-exported

  [4] API PREFIX: /api/xai → /api/v1/xai
      Phải khớp với convention /api/v1/* đang dùng trong analysis.py, auth.py

  [5] LOADING: Eager load → Lazy-load singleton
      Gốc:  gradcam_svc = GradCAMService(...)  ← Load lúc import, tốn RAM
      Sửa:  EigenCAMService.get_instance()      ← Lazy-load khi có request đầu tiên
      Lý do: Tránh OOM trên Render Free 512MB, giống pattern Best9ONNXService

  [6] FRONTEND: Component riêng XAIPanel.tsx → Tích hợp vào PreviewModal
      Gốc:  Tạo component riêng biệt
      Sửa:  Thêm tab/toggle heatmap vào PreviewModal trong cell-review-gallery.tsx
      Lý do: Không phá vỡ UX hiện tại, user đã quen click cell → preview

  [7] ONNX INTERMEDIATE OUTPUTS: Export lại model → Modify graph runtime
      Gốc:  Cần re-export model từ Keras
      Sửa:  Dùng onnx library thêm intermediate output node lúc runtime
      Lý do: Không cần retrain, không cần .keras file

  [8] TEMPERATURE SCALING: Áp dụng trên logits → Áp dụng trên probabilities
      Phải khớp với _apply_temperature_scaling() trong classifier_service.py:
      logits = log(clip(probs)) → scaled = logits / T → softmax lại

  [9] KHUYẾN NGHỊ .KERAS PATH: Loại bỏ
      Gốc:  "Tạo 2 execution path — .onnx + .keras"
      Sửa:  Chỉ dùng .onnx (hệ thống đã loại bỏ hoàn toàn TF/Keras)

"""
xai_service.py — EigenCAM for ONNX models (no gradient needed)
"""
import base64
import logging
from pathlib import Path
from typing import Any

import cv2
import numpy as np
import onnx
import onnxruntime as ort
from PIL import Image

from backend.app.core.paths import CLASSIFIER_MODELS_DIR

logger = logging.getLogger(__name__)

TEMPERATURE = 0.5204
TARGET_LAYER_KEYWORDS = [
    "block_13_expand_relu",   # Phase 3 unfreeze layer
    "block_13_expand",
    "Conv_1",                 # MobileNetV2 final conv
]
CLASS_NAMES = ["BNE", "EO", "IG", "MYO", "NEU", "PMY", "SNE"]


def _softmax(x: np.ndarray) -> np.ndarray:
    e = np.exp(x - np.max(x, axis=-1, keepdims=True))
    return e / np.sum(e, axis=-1, keepdims=True)


def _to_base64_png(img_array: np.ndarray) -> str:
    _, buf = cv2.imencode(".png", img_array)
    return base64.b64encode(buf.tobytes()).decode("utf-8")


def _find_target_layer_output(model: onnx.ModelProto) -> str | None:
    """Tìm output node của target conv layer trong ONNX graph."""
    for keyword in TARGET_LAYER_KEYWORDS:
        for node in model.graph.node:
            if keyword.lower() in node.name.lower():
                if node.output:
                    return node.output[0]
    # Fallback: last Conv/Relu node
    conv_outputs = []
    for node in model.graph.node:
        if node.op_type in ("Conv", "Relu", "Clip") and node.output:
            conv_outputs.append(node.output[0])
    return conv_outputs[-1] if conv_outputs else None


def _add_intermediate_output(model_path, target_output_name):
    """Thêm intermediate output vào ONNX graph (runtime, không cần re-export)."""
    model = onnx.load(str(model_path))
    existing = {o.name for o in model.graph.output}
    if target_output_name not in existing:
        info = onnx.helper.make_tensor_value_info(
            target_output_name, onnx.TensorProto.FLOAT, None
        )
        model.graph.output.append(info)
    return model


class EigenCAMService:
    """
    Lazy-loaded singleton — chỉ load khi có request XAI đầu tiên.
    Pattern giống Best9ONNXService và OnnxClassifierAdapter.
    """
    _instance = None

    def __init__(self, model_path: Path):
        self._model_path = model_path
        self._session = None
        self._input_name = None
        self._output_names = None
        self._target_layer_output = None

    @classmethod
    def get_instance(cls, model_id=None):
        if cls._instance is None:
            model_path = cls._resolve_model_path(model_id)
            cls._instance = cls(model_path)
        return cls._instance

    @classmethod
    def _resolve_model_path(cls, model_id):
        for name in ["mobilenetv2_final.onnx", "MobilenetV2.onnx"]:
            p = CLASSIFIER_MODELS_DIR / name
            if p.exists() and p.stat().st_size > 0:
                return p
        onnx_files = sorted(CLASSIFIER_MODELS_DIR.glob("*.onnx"))
        if onnx_files:
            return onnx_files[0]
        raise RuntimeError("No ONNX classifier found for XAI")

    def _initialize(self):
        if self._session is not None:
            return
        logger.info("XAI: Loading ONNX for EigenCAM: %s", self._model_path.name)

        # 1. Tìm target layer
        model = onnx.load(str(self._model_path))
        self._target_layer_output = _find_target_layer_output(model)
        if not self._target_layer_output:
            raise RuntimeError("Cannot find target conv layer in ONNX graph")

        # 2. Thêm intermediate output (không cần re-export model)
        model = _add_intermediate_output(self._model_path, self._target_layer_output)

        # 3. Tạo session từ modified graph
        opts = ort.SessionOptions()
        opts.intra_op_num_threads = 1
        opts.inter_op_num_threads = 1
        self._session = ort.InferenceSession(
            model.SerializeToString(),
            sess_options=opts,
            providers=["CPUExecutionProvider"],
        )
        self._input_name = self._session.get_inputs()[0].name
        self._output_names = [o.name for o in self._session.get_outputs()]

    def compute_eigencam(self, image, class_idx=None) -> dict:
        self._initialize()

        # 1. Preprocess — ĐÚNG mobilenet_v2 format
        if isinstance(image, np.ndarray):
            img_rgb = image
        else:
            img_rgb = np.asarray(image.convert("RGB"), dtype=np.uint8)
        img_resized = cv2.resize(img_rgb, (224, 224))
        img_norm = img_resized.astype(np.float32) / 127.5 - 1.0  # ← mobilenet_v2
        inp = np.expand_dims(img_norm, 0)  # (1,224,224,3) NHWC ← ĐÚNG

        # 2. Inference → logits + feature maps
        outputs = self._session.run(self._output_names, {self._input_name: inp})

        logits, feature_maps = None, None
        for out in outputs:
            if len(out.shape) == 2:    # (1, num_classes)
                logits = out
            elif len(out.shape) == 4:  # (1, H, W, C)
                feature_maps = out

        if logits is None or feature_maps is None:
            return {"success": False, "error": "Cannot separate logits/feature_maps"}

        # 3. Temperature scaling (khớp với classifier_service.py)
        scaled_logits = np.log(np.clip(logits[0], 1e-7, 1.0)) / TEMPERATURE
        probs = _softmax(scaled_logits)

        if class_idx is None:
            class_idx = int(np.argmax(probs))

        # 4. EigenCAM: PCA trên feature maps
        fm = feature_maps[0]  # (H, W, C)
        if fm.shape[0] < fm.shape[-1]:  # NCHW → NHWC
            fm = np.transpose(fm, (1, 2, 0))
        h, w, c = fm.shape
        fm_flat = fm.reshape(-1, c)
        fm_centered = fm_flat - fm_flat.mean(axis=0)
        try:
            U, S, _ = np.linalg.svd(fm_centered, full_matrices=False)
            cam = (U[:, 0] * S[0]).reshape(h, w)
        except np.linalg.LinAlgError:
            cam = fm.mean(axis=-1)  # fallback

        # 5. ReLU + normalize + upsample
        cam = np.maximum(cam, 0)
        if cam.max() > 0:
            cam = cam / cam.max()
        cam = cv2.resize(cam, (224, 224))

        # 6. Heatmap + overlay
        heatmap = cv2.applyColorMap((cam * 255).astype(np.uint8), cv2.COLORMAP_JET)
        overlay = cv2.addWeighted(
            cv2.cvtColor(img_resized, cv2.COLOR_RGB2BGR), 0.5,
            heatmap, 0.5, 0
        )

        nc = min(len(probs), len(CLASS_NAMES))
        return {
            "success": True,
            "top_class": CLASS_NAMES[class_idx] if class_idx < nc else f"class_{class_idx}",
            "confidence": float(probs[class_idx]),
            "calibrated_probs": {CLASS_NAMES[i]: float(probs[i]) for i in range(nc)},
            "heatmap_b64": _to_base64_png(heatmap),
            "overlay_b64": _to_base64_png(overlay),
        }

    def release(self):
        self._session = None

    @classmethod
    def reset(cls):
        if cls._instance:
            cls._instance.release()
            cls._instance = None
```

  ✗ Gốc: NCHW (2,0,1) transpose            → ✓ Sửa: NHWC expand_dims
  ✗ Gốc: Eager load constructor             → ✓ Sửa: Lazy singleton get_instance()

"""
xai.py — XAI API Router (prefix /api/v1/xai)
"""
import gc
from fastapi import APIRouter, File, Form, HTTPException, Request, UploadFile
from fastapi.concurrency import run_in_threadpool

from backend.app.core.logging import get_logger
from backend.app.core.rate_limit import limiter
from backend.app.core.config import settings
from backend.app.core.security import validate_image_upload
from backend.app.services.classifier_service import read_image_from_bytes

logger = get_logger("xai_routes")
router = APIRouter(prefix="/api/v1/xai", tags=["XAI"])


@router.post("/gradcam")
@limiter.limit(settings.inference_rate_limit)
async def get_gradcam(
    request: Request,
    file: UploadFile = File(...),
    class_idx: int | None = Form(None),
    model_id: str | None = Form(None),
):
    raw_bytes = await file.read()
    validate_image_upload(file, raw_bytes)
    image = read_image_from_bytes(raw_bytes)

    # Lazy import tránh load XAI service lúc startup
    from backend.app.services.xai_service import EigenCAMService

    def _compute():
        svc = EigenCAMService.get_instance(model_id)
        return svc.compute_eigencam(image, class_idx=class_idx)

    try:
        result = await run_in_threadpool(_compute)
    except Exception as exc:
        raise HTTPException(500, f"Lỗi XAI: {exc}")
    finally:
        gc.collect()

    if not result.get("success"):
        raise HTTPException(500, result.get("error", "XAI failed"))
    return result
```

KHÁC BIỆT SO VỚI CODE GỐC:
  ✗ Gốc: prefix="/api/xai"                  → ✓ Sửa: prefix="/api/v1/xai"
  ✗ Gốc: Eager load GradCAMService          → ✓ Sửa: Lazy import trong handler
  ✗ Gốc: tempfile + cv2.imread              → ✓ Sửa: read_image_from_bytes (PIL)
  ✗ Gốc: Không có rate limit                → ✓ Sửa: @limiter.limit() như analysis.py
  ✗ Gốc: Không có validate_image_upload     → ✓ Sửa: Dùng security helper có sẵn
  ✗ Gốc: Không gc.collect()                 → ✓ Sửa: Free RAM sau mỗi request

================================================================================
7. LƯU Ý TRIỂN KHAI
================================================================================

RAM:
  - EigenCAM session chiếm ~12MB (model 11.5MB + overhead)
  - Render Free Tier có 512MB → đủ chạy song song với classifier
  - Nếu cần, gọi EigenCAMService.reset() để giải phóng

ONNX Graph Modification:
  - Dùng onnx.load() + thêm output node → SerializeToString()
  - Không cần lưu file tạm, tất cả trong memory
  - Chỉ modify 1 lần khi initialize, sau đó session được cache

Accuracy:
  - EigenCAM < Grad-CAM về mặt lý thuyết (không dùng gradient)
  - Nhưng đủ tốt cho medical imaging (kết quả tương đương ScoreCAM)
  - Nếu cần chính xác hơn → thay bằng ScoreCAM (chạy N forward pass)

Bảo mật:
  - Dùng validate_image_upload() có sẵn (check size, type)
  - Rate limit giống analysis endpoint
  - Không lưu file tạm (xử lý in-memory)
